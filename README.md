# LearnByInterrogation

Write down what you're learning — maths, code, philosophy, anything — and watch it become a
living knowledge graph. LearnByInterrogation maps your notes into concepts and connections,
spots the gaps in your understanding (undefined terms, isolated ideas, unconnected concepts),
and puts **Socrates** in the room with you: a relentless AI interrogator that asks questions
instead of giving answers, forcing you to actually own what you think you know.

Everything — your notes, their embeddings, and the knowledge graph — lives entirely in your
browser (IndexedDB). Nothing is ever uploaded anywhere, except the questions themselves, which
are generated by an LLM you connect with your own API key (BYOK via [Groq](https://groq.com)).

Built for the August AI Challenge.

## How it works

1. **Write** — jot down a learning in the composer at the bottom: a formula, a definition, a
   claim, a half-formed idea. Tag it (`#concept`, `#definition`, `#question`, `#insight`,
   `#formula`).
2. **Embed** — a small sentence-embedding model ([`Xenova/all-MiniLM-L6-v2`](https://huggingface.co/Xenova/all-MiniLM-L6-v2),
   ~25MB, quantized) runs entirely client-side in a Web Worker via
   [transformers.js](https://github.com/huggingface/transformers.js) to embed your note. No
   server round-trip.
3. **Map** — a local, heuristic graph builder extracts candidate concepts from your notes
   (bold terms, title-case phrases, definitional patterns, recurring n-grams) and links them
   to the notes that mention them, and to each other by co-occurrence. Note-to-note similarity
   edges are added from the embeddings.
4. **Find gaps** — the same builder flags: concepts you mention but never define, concepts
   that are disconnected from everything else you know, and pairs of concepts that are
   semantically close (by embedding similarity) but that you've never explicitly connected.
5. **Interrogate** — pick a gap, a concept, or a note (or just start typing), and Socrates —
   powered by your chosen Groq model — retrieves the most relevant excerpts from your own
   notes (a lightweight local RAG pipeline) and questions you about them: Socratic, short,
   pointed, never just handing you the answer.

## Setting up your own Groq API key (BYOK)

The app never ships with a shared API key — you bring your own, and it's used only from your
browser directly to Groq's API.

1. Go to [console.groq.com/keys](https://console.groq.com/keys) and sign in — it's free.
2. Click **Create API Key** and copy it.
3. Open **Settings** in the app and paste it in. It's stored only in your browser's local
   IndexedDB, never sent anywhere but Groq.

## Local development

```bash
npm install
npm run dev
```

## Deployment

This repo deploys automatically to GitHub Pages via GitHub Actions
(`.github/workflows/deploy.yml`) on every push to `main`. In the repo settings, set
**Settings → Pages → Source** to **GitHub Actions**.

## Stack

- Vite + React + TypeScript + Tailwind CSS v4
- [React Flow](https://reactflow.dev) for the knowledge graph
- [transformers.js](https://github.com/huggingface/transformers.js) (`@huggingface/transformers`)
  running `Xenova/all-MiniLM-L6-v2` in a Web Worker for local embeddings
- [Groq](https://groq.com) (via `groq-sdk`, BYOK) for the Socratic interrogation
- IndexedDB (via `idb`) for all local persistence
